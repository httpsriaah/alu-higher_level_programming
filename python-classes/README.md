# Python - Classes and Objects

This project introduces object-oriented programming in Python 3: classes, instances, private attributes, properties, getters and setters, and validation of attribute values.

## Requirements

* Ubuntu 20.04 LTS, python3 (3.8.5)
* Code style: pycodestyle 2.7.*
* All files are executable and documented

## Files

* `0-square.py` - empty Square class
* `1-square.py` - Square with a private size
* `2-square.py` - size validation
* `3-square.py` - area of a square
* `4-square.py` - access and update the private size with a property
* `5-square.py` - printing a square
* `6-square.py` - coordinates of a square
