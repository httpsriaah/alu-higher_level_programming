# Python - Classes and Objects

This project covers classes, objects, private attributes, properties,
getters and setters in Python 3.

## Files

* `0-square.py` - empty Square class
* `1-square.py` - Square with a private size
* `2-square.py` - size validation
* `3-square.py` - area of a square
* `4-square.py` - access and update the private size with a property
* `5-square.py` - printing a square
* `6-square.py` - coordinates of a square
